# 할 일 알림

할 일의 종 아이콘에서 날짜와 시간을 지정해 일회성 알림을 예약·변경·해제한다.
완료·삭제·휴지통 이동된 항목은 예약 대상에서 제외하고, 복구할 때 아직 미래인 예약만 다시 등록한다.

## 예약 화면

- 메모 색에 맞는 밝은 배경과 차분한 권한 안내를 사용한다.
- 최초 예약 시 macOS 알림 허용을 요청한다. 권한이 꺼져 있으면 알림 설정으로 이동하는 버튼을 표시한다.
- 권한 확인 중에도 팝오버를 유지하고, 등록 성공 후 예약 완료 메시지와 시간을 표시한다.
- 날짜 선택기는 분 단위다. 화면에 보이지 않는 초는 예약에 포함하지 않는다.
- 등록에 실패하면 기존 예약 시간을 복구한다. 예약 날짜는 즉시 저장한다.

## 확인 결과

2026-09-07 로컬에서 한국어·영어 환경 테스트를 진행했다.
권한 거부, macOS가 오류로 반환하는 권한 거부, 예약 성공과 저장,
변경 실패 시 기존 예약 복구, 권한 응답 중 항목 완료, 지난 시간 거부를 검사한다.
기존 데이터 호환과 탭 병합 후 알림 보존, 삭제·복구에 따른 예약 대상도 검사한다.

Xcode로 빌드한 앱에서 23:54:00 예약의 배너 표시와 소리 재생을 macOS 기록으로 확인했다.
권한 안내와 예약 화면은 실제 앱에서 사용자 확인을 거쳤다.
앱 종료 상태의 전달, 절전 복귀, 집중 모드에 따른 시스템 표시 동작은 별도 확인 대상이다.
