# Posteight

**맥을 위한 사적인 포스트잇 — 보이는 시점은 내가 정한다.**

[![Latest release](https://img.shields.io/github/v/release/hmjlon/posteight?label=download)](https://github.com/hmjlon/posteight/releases/latest)

Posteight 는 오늘 할 일을 바탕화면에 꺼내 둔다. 작업이 실제로 일어나는 자리마다
독립된 작은 창을 놓고, 누가 다가오면 감춘다.

[English](README.md) · 한국어

![바탕화면에 떠 있는 Posteight 메모들](docs/images/posteight-desktop-ko.jpg)

## 설치

### 요구 사항

| | |
| --- | --- |
| macOS | 14 (Sonoma) 이상 |
| Mac | Apple Silicon 전용 — `ARCHS` 가 `arm64` 로 고정되어 있어 Intel Mac 은 지원하지 않는다 |
| 인터페이스 언어 | 한국어 / 영어, 설정에서 전환 |

### Homebrew

```bash
brew install --cask hmjlon/tap/posteight && xattr -dr com.apple.quarantine /Applications/Posteight.app
```

뒤쪽 절반이 앱을 열 수 있게 해 주는 부분이다 — [처음 열 때](#처음-열-때) 를 보라.
다음 버전부터는 `brew upgrade` 로 받고, 받을 때마다 저 `xattr` 한 줄이 다시 필요하다.

### 내려받기

또는 [Releases](https://github.com/hmjlon/posteight/releases) 에서 최신 `.dmg` 를 내려받아 열고,
**Posteight** 를 **응용 프로그램** 으로 끌어다 놓는다.

### 처음 열 때

Posteight 는 아직 Apple 공증을 받지 않았다. 어느 쪽으로 설치하든 앱에 격리 속성이 붙고,
macOS 는 확인할 수 없는 격리된 앱의 실행을 막는다. 그 속성을 떼어 내는 게 가장 짧은
길이다. Posteight 를 처음 열기 전에 실행한다.

```bash
xattr -dr com.apple.quarantine /Applications/Posteight.app
```

**터미널을 쓰지 않는다면** 시스템 설정으로 간다. 단계가 **연달아** 일어나야 한다.

1. Posteight 를 연다. 경고가 뜨고 실행이 거부된다.
2. **곧바로** **시스템 설정 → 개인정보 보호 및 보안** 을 열고 보안 항목까지 내려간다.
3. **그래도 열기** 를 누르고 인증한다.

Apple 은 이 버튼을 차단된 실행 **이후 약 1시간 동안만** 보여 준다. 그전에는 아예 없다.
버튼이 보이지 않으면 Posteight 를 한 번 더 열고 바로 다시 들어간다. 앱을 Control-클릭해서
**열기** 를 누르는 것도 우회가 되지 않는다. macOS 15 에서 없어진 방법이다.

어느 쪽이든 `brew upgrade` 를 포함해 새 버전을 받을 때마다 다시 필요하다. Posteight 는
ad-hoc 서명이라 빌드마다 서명이 달라지고, macOS 는 새 버전이 이미 승인한 그 앱인지
알아보지 못한다.

공증에는 유료 Apple Developer Program 멤버십이 필요하다. 그전까지는 앱을 직접 빌드한
사람이 아닌 이상 이 단계를 피할 수 없다.

## 사용하기

### 메모 창

<img src="docs/images/posteight-note-ko.png" alt="탭 두 개와 세부사항이 달린 고정 항목, 펜 줄이 그어진 완료 항목, 알림을 예약한 항목이 보이는 메모 창" width="300">

메모는 각자 떠 있는 창이고, 놓아둔 자리를 기억한다. 모니터가 여러 대여도 마찬가지다. 안쪽의
컴팩트한 탭 바에는 목록을 열 개까지 둘 수 있다. 탭은 폭을 나눠 쓰고, 메모를 가장 좁게 줄이거나
탭이 너무 많아 하나하나를 누르기 어려워지면 현재 탭과 나머지 탭 목록 메뉴로 접힌다.

- 독립적으로 떠 있고 크기를 조절할 수 있는 메모 창 여러 개. 새 메모는 지금 작업 중인 화면에 뜬다
- 메모마다 붙는 탭. 활성 탭을 한 번 더 누르면 그 자리에서 이름을 고친다. 메모를 다른 메모 위에 놓으면 탭이 합쳐진다
- 완료할 때 펜으로 줄을 긋는 애니메이션 체크리스트
- 필통에서 고르는 종이 색, 펜 색, 펜촉, 탭 아이콘, 메모의 폰트와 글자 크기
- 메모 창을 닫아도 — 닫기 버튼이든 Esc 든 — 숨겨질 뿐 메모는 그대로 남는다
- 내용 미리보기와 복원, 영구 삭제가 되는 휴지통. 30일이 지난 항목은 알아서 사라진다

### 메뉴 막대

<img src="docs/images/posteight-menubar.png" alt="할 일이 끝날 때마다 이어서 그려지는 무한대 고리 모양의 Posteight 상태 아이템" width="44">

Posteight 에는 메인 창이 없다. 상태 아이템이 유일한 상설 표면이다. Posteight 의 8 을 작은
무한대 고리로 그리고, 그 옆에 남은 일이나 완료한 일의 개수를 둔다. 숫자 없이 고리만 둘 수도 있다.
할 일이 끝날 때마다 고리가 이어서 그려지고, 남은 게 없으면 한 바퀴가 닫힌다. 누르면 팝오버가
열리고, 거기서 새 메모, 메모 검색, 메모 보기, 모든 메모 숨기기, 휴지통, 앱 잠그기(앱 잠금을 켠
경우), 설정, 종료로 간다.

설정에서는 언어, 상태 아이템이 세는 것, 메모를 다른 앱 위에 띄울지와 화면 공유·스크린샷에서
감출지, 알림에 할 일 내용을 보일지, 앱 잠금, 기본 폰트, 저장과 백업, Dock 아이콘을 정한다.
Dock 아이콘은 기본으로 켜져 있어서 실행 중인 Posteight 를 Dock 과 Command-Tab 으로 부를 수
있고, 누르면 메모 창이 다시 나온다. 끄면 메뉴 막대에만 사는 앱이 된다.

### 검색과 목록 정리

- 메뉴 막대 → **메모 검색…**에서 모든 탭의 이름·제목·할 일·세부사항을 찾는다. 결과를 누르면 해당 메모의 일치하는 위치로 이동한다.
- 할 일의 손잡이를 끌어 순서를 바꾸거나, 우클릭 메뉴에서 다른 메모로 옮긴다. 상단 고정과 완료 상태별 정렬도 지원한다.
- 할 일별로 알림 시간을 예약할 수 있다. 설치된 앱에서 알림 권한을 허용해야 한다. 알림에는 할 일 내용 대신 짧은 안내만 뜨고, **설정 → 알림 → 알림 본문에 할 일 내용 표시**를 켜면 내용이 보인다.
- 기본 폰트와 글자 크기는 설정에서 고르고, 메모마다 다른 폰트와 크기는 그 메모의 필통에서 고른다. TTF·OTF·TTC 폰트 파일을 직접 추가할 수 있다.

### 단축키

| 키 | 동작 |
| --- | --- |
| Command-N | 새 메모 |
| Command-T | 현재 메모에 탭 추가 |
| Command-Delete | 현재 탭을 휴지통으로 보내기 (확인 후) |
| Command-Z / Shift-Command-Z | 메모 전체 실행 취소 / 다시 실행 |
| Command-A → Command-C | 현재 탭 전체 선택 후 복사 |
| Esc | 메모 숨기기 |
| Command-, | 설정 |

메모 창의 단축키는 한글 입력 상태에서도 동작한다. 입력칸을 편집하는 중에는 Command-A 가 그
입력칸 안에서만 전체를 고른다.

### 저장 오류와 백업

저장된 파일을 읽지 못하거나 이전 버전의 데이터를 가져오지 못하면 원본을 보호하기 위해 편집과 저장을 멈춘다. 메뉴 막대와 **설정 → 저장과 백업**에 안내가 나오며, 문제를 해결한 뒤 **다시 시도**할 수 있다. 저장에 실패한 편집은 앱이 실행 중인 동안 메모리에 남으므로, 앱을 닫기 전에 저장 오류를 해결한다.

정상적으로 읽은 메모는 실행 후 첫 저장 전에 `backup.json`으로 자동 백업한다. **현재 메모 백업**은 그 백업을 현재 내용으로 교체한다. **백업 복원…**은 메모와 휴지통을 백업 상태로 되돌리고, 복원 전 파일은 `BeforeRestore-…` 폴더에 별도로 보관한다. 복원 중 종료되면 다음 실행에서 이어서 복원한다.

백업에는 메모와 휴지통이 들어 있으며 설정과 폰트 파일은 들어 있지 않다. 백업은 같은 Mac의 저장 폴더에 있으므로 디스크 고장에 대비한 외부 백업을 대신하지 않는다. 휴지통의 30일 자동 삭제와 별개로 백업·복원 전 원본은 남아 있을 수 있다. 필요 없어진 `backup.json`과 `BeforeRestore-…` 폴더는 **설정 → 앱 → 폴더 열기**에서 직접 삭제할 수 있다.

### 언어

<img src="docs/images/posteight-settings-ko.png" alt="언어 항목이 맨 위에 있는 Posteight 설정 창" width="380">

Posteight 는 한국어와 영어로 읽힌다. 고르기 전까지는 맥의 언어를 따른다.
**설정 → 언어** 를 바꾸면 앱이 직접 그리는 모든 문구가 재실행 없이 바뀐다. 팝오버, 메모의
조작 버튼, 휴지통까지 — 열려 있는 메모 창도 누르는 즉시 따라온다.
직접 적은 것은 적은 그대로 남는다. 메모 내용, 탭 이름, 제목은 번역하지 않는다.

macOS 가 직접 그리는 메뉴(파일, 편집, 윈도우)는 여전히 시스템 언어를 따른다.

### 메모가 저장되는 곳

Posteight 는 App Sandbox 안에서 돌기 때문에 메모는 자기 컨테이너에 저장된다 —
`~/Library/Containers/com.younjiyoung.posteight/Data/Library/Application Support/Posteight/`.
파일 권한은 해당 사용자만 읽고 쓸 수 있도록 제한한다. 파일은 암호화하지 않으며, 같은 사용자 권한으로 실행되는 다른 프로그램의 접근까지 막는 것은 아니다.
설정 → 앱 → 폴더 열기로 갈 수 있다. 샌드박스 이전 버전에서 쓰던 메모는 첫 실행에 한 번
복사되고, 예전 폴더는 그대로 남는다.

계정도, 동기화도, 사용 정보 수집도 없다. 내보내기는 명시적으로만 일어난다 — 메모 창에서
Command-A 로 현재 탭을 고르고 Command-C 로 복사하는 것이 전부이고, 클립보드 매니저가
히스토리에 남기지 않도록 표식을 붙인다.

**설정 → 앱 잠금** 을 켜면 메뉴 막대에서 Posteight 전체를 잠글 수 있다. 잠금 해제에는
Touch ID 또는 Mac 로그인 암호를 사용하므로 Posteight가 별도 비밀번호를 저장하지 않는다.
잠긴 동안에는 메모, 휴지통과 상태 개수를 보여 주지 않으며, 잠금 기능을 켠 뒤에는
알림에도 할 일 내용을 싣지 않는다. 앱을 다시 실행하면 본인 확인 전까지 잠긴 상태로 시작한다.
이 잠금은 화면에서 내용을 가리는 기능이고 저장된 메모 파일을 암호화하지는 않는다.

화면을 잠그면 떠 있던 메모가 알아서 사라지고, 풀면 있던 자리로 돌아온다. 직접 숨겨 둔
메모는 잠금과 상관없이 숨겨진 채로 남는다. 그리고 메모 창은 화면 공유에도, 화면 녹화에도,
스크린샷에도 찍히지 않는다 — 회의에서 화면을 넘겨도 메모는 내 화면에만 있다. 메모를 직접
보여 주려면 **설정 → 노트** 에서 끈다. 둘 다 추가 권한을 요구하지 않는다.

이건 시각적 프라이버시이지 보안 금고가 아니다. 자리를 비우거나 화면을 공유할 때 우연한
노출을 줄여 주지만, 잠기지 않은 화면에 지금 보이는 내용을 옆사람이 읽는 것까지 막지는 못한다.
